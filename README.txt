AGENTE DE EMPLEO — CROACIA

Esta versión incluye una interfaz rediseñada y un backend local para consultar páginas públicas.

1) Requisito: Python 3.
2) Abrir una terminal en esta carpeta.
3) Ejecutar: python server.py
4) Abrir: http://127.0.0.1:8765

El botón “Buscar nuevos empleos” consulta las fuentes públicas configuradas en server.py y clasifica la evidencia encontrada.

IMPORTANTE:
- La clasificación es una preselección, no una confirmación legal.
- “Alojamiento gratuito” solo se considera confirmado cuando el texto contiene expresiones explícitas de gratuidad o coste asumido por el empleador.
- El permiso de residencia/trabajo para Colombia sigue requiriendo verificación específica.
- Los grupos privados de Facebook no se automatizan sin acceso autorizado.
- No hay envío externo automático: la autorización queda separada y explícita.
